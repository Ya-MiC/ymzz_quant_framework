## 見賢思齊：這輪真正加進來的

只加可選路徑，既有的 httpx、回測引擎、儀表板、runner、Kraken 教程都留著。

1. **Polymarket 官方 SDK（beta）。** 請求帶 `adapter=sdk` 時，用 `polymarket.PublicClient` 讀市場與 `list_price_history`。只讀公開資料，不建 `SecureClient`，不要私鑰。套件沒裝就退回 Gamma 與 CLOB 的 httpx，並在結果裡標 `httpx-fallback` 與 `beta`。安裝是 `pip install -e ".[polymarket]"`，不在預設依賴裡。
2. **A 股規則。** 對照 AKQuant 文件裡「T+1、一手 100、漲跌停、停牌要用黃金測試」的想法，規則寫在自己的引擎裡，沒有複製他們的 Rust 或 Python。日線買進那一根不能賣。漲停不成交買單，跌停不成交賣單，止損也過不了板。幅度：ST 5%，主板 10%，創業板 300/301 與科創板 688/689 為 20%，用前一交易日收盤。`suspended=True` 的那根沒有成交。來源沒有停牌旗標時，不把成交量 0 猜成停牌。
3. **ccxt 現貨。** 來源選 `ccxt` 並帶 `ccxt_exchange` 才會走到它，例如還沒手寫解析的交易所。okx、binance、kraken 的解析不變。永續仍走原來的兩家，因為資金費不能漏。沒裝 ccxt 就清楚報錯，不改接別的來源。
4. **給外部引擎的 CSV。** `ymzz.external_export.export_research_csv` 寫 `ohlcv.csv`（time、open、high、low、close、volume）和 `signals.csv`（time、signal）。這不是 Nautilus 或 Lean 的官方格式，只是一份他們可以在自己的專案裡讀的研究匯出。

## 外部引擎怎麼用這份 CSV

不要在這個虛擬環境 `pip install nautilus_trader` 或把 Lean 的原始碼夾進來。

1. 在本倉庫跑完回測，呼叫 `export_research_csv(bars, signals, "export")`。
2. Nautilus：在另一個、授權接受 LGPL-3.0 的環境安裝 [NautilusTrader](https://github.com/nautechsystems/nautilus_trader)，用他們自己的 CSV / 資料目錄工具讀 `ohlcv.csv`。訊號檔只給研究對照，不當成他們的策略程式。
3. Lean：在另一個環境照 [QuantConnect/Lean](https://github.com/QuantConnect/Lean) 的說明建立專案，把 `ohlcv.csv` 當成自訂 CSV 行情。Apache-2.0 允許這樣用，仍然不要把 Lean 放進本倉庫的依賴。

## 刻意沒有做的

- 不把 AKQuant、akshare、vnpy、Jesse、Hummingbot、Condor 加進依賴。規則上的缺口用自己的測試補，資料上的缺口還沒有大到要換掉現有三個 A 股來源。
- 不複製 Kelows/million 或 CabalSpy 的任何檔案。跟單仍是公開地址、公共 RPC、延遲之後的 K 線。
- 不把封存的 `py-clob-client` 接回來。
